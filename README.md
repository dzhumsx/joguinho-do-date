# Joguinho do Date / Date Game

[🇧🇷 Português](#-português) | [🇺🇸 English](#-english)

---

## 🇧🇷 Português

Aplicativo web interativo para convidar alguém para sair. 

### Como funciona:
1. **Gerador:** Acesse o site e digite seu e-mail para criar um link único.
2. **Convite:** Envie o link gerado para a pessoa. O botão "Não" foge do cursor.
3. **Questionário:** Ao conseguir clicar em "Sim", a pessoa escolhe a data, hora, comida e a "vibe" do encontro.
4. **Notificação:** As respostas escolhidas são enviadas automaticamente para o seu e-mail.

### Como rodar localmente:
```bash
git clone https://github.com/dzhumsx/joguinho-do-date.git
cd joguinho-do-date
npm install
npm run dev
```

---

## 🇺🇸 English

An interactive web app to ask someone on a date.

### How it works:
1. **Generator:** Open the app and enter your email to create a unique link.
2. **Invitation:** Send the generated link to your person. The "No" button evades the cursor.
3. **Questionnaire:** When they finally click "Yes", they select the date, time, food, and activity vibe.
4. **Notification:** The selected answers are automatically forwarded to your email.

### How to run locally:
```bash
git clone https://github.com/dzhumsx/joguinho-do-date.git
cd joguinho-do-date
npm install
npm run dev
```
